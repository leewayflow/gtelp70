# 지텔프 70 트레이너

지텔프 Level 2 목표 70점을 위한 연습 앱입니다.

- 28일 학습 플랜과 목표 점수 계산기
- 문법: Day 1~40 세트(실제 시험 유형 비율), 오답노트
- 청취: 파트별 8개 지문, 녹음 포함
- 독해: Part 1~4 지문 5개
- 단어: 동의어 카드 36개, 녹음 포함

진도와 오답노트는 각자 브라우저에 저장됩니다. 플랜 탭의 "기록 내보내기/가져오기"로 다른 기기로 옮길 수 있습니다.

문제와 지문은 연습용으로 새로 만든 것이며 실제 기출 문제가 아닙니다. 녹음은 Kokoro TTS로 생성했습니다.
